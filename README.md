# monolit proxy

Панель для своего VPN-сервера на Xray. Ставится одной командой на VPS, дальше всё делается в браузере: добавили человека — он получил ссылку, открыл её на телефоне и подключился в пару нажатий. Сколько трафика он потратил и до какого числа у него доступ, видно в списке.

## Как это выглядит для человека

Вы отправляете ему ссылку. Она открывает страницу подписки: там кнопки установить приложение (INCY или Happ, для iPhone, Android и компьютера) и добавить подписку. Ключи копировать не нужно. Если вы поменяете сервер, домен или протоколы, приложение подхватит изменения само при обновлении подписки.

## Что умеет

- **Пользователи** — у каждого своя ссылка, лимит трафика и срок. Трафик по дням, QR-код для телефона
- **Протоколы** — VLESS Vision, XHTTP, Hysteria2 и AmneziaWG (для AmneziaVPN). Лишнее выключается в окне «Протоколы»
- **Несколько серверов** — второй сервер добавляется одной командой из админки. Он может работать отдельным сервером или мостом: например, сервер в России принимает подключения, а наружу выходит через зарубежный. Российские сайты мост открывает сам, со своего адреса
- **Наборы подключений** — кому какие серверы показывать в приложении
- **Маршруты** — какие сайты пускать напрямую, через Cloudflare WARP или блокировать
- **Бэкап** — пользователи, ссылки и настройки одним файлом. Восстанавливается перетаскиванием на этот же или новый сервер
- **Прокси для Telegram** (MTProto) и SOCKS5 с паролем — по желанию
- **Рядом с сайтами** — если на сервере уже есть сайты в nginx, они продолжат работать
- **Смена домена без потерь** — старый домен остаётся запасным, старые ссылки работают
- **Обновление кнопкой** — новые версии приходят из релизов этого репозитория

Клиентские конфиги собираются по шаблону [autoXRAY](https://github.com/xVRVx/autoXRAY). Новый шаблон monolit забирает сам и перед применением проверяет его через `xray run -test`: если проверка не прошла, остаётся прежний.

## Установка

Нужен сервер на Debian или Ubuntu, доступ root и домен, который смотрит на этот сервер.

```bash
git clone https://github.com/rawsense/monolit-proxy.git
cd monolit-proxy
bash install.sh
```

Установщик спросит домен, покажет, что собирается сделать, и после подтверждения поставит Xray, выпустит сертификат и настроит nginx. В конце он покажет адрес админки, логин и пароль.

Без вопросов: `bash install.sh --domain vpn.example.ru`. Все ключи с пояснениями — в начале `install.sh`.

Если Xray уже настроен через autoXRAY, monolit возьмёт его входы. Заменить настройку autoXRAY своей можно так: `bash install.sh --reconfigure --replace-autoxray`. Прежние ключи autoXRAY после этого перестанут работать.

**Обновление.** Кнопкой в админке («Обслуживание») или повторным запуском `install.sh`. Пользователи, адрес админки и пароль сохраняются.

**Удаление.** `bash install.sh --uninstall` вернёт nginx и Xray как было до установки. База пользователей останется в `/var/lib/monolit`.

**Безопасность.** Перед любой правкой конфигов Xray и nginx установщик кладёт копии в `/root/backups`. Если после правки проверка не прошла или сайты на сервере перестали открываться, он сам откатывает изменения.

## Для разработчиков

- `server/` — сервер на Node 24 без зависимостей (база — `node:sqlite`)
- `ui/src/` — страницы админки и подписки; `node ui/build.mjs` собирает их в `ui/dist`. `admin.html` и `sub.html` открываются и без сервера, на демо-данных
- `awg/` — сервер AmneziaWG в отдельном контейнере, собирается на сервере из исходников amneziawg-go
- тесты: `node --test --test-timeout=30000 --test-force-exit test/awg.test.mjs`

## Клиент для Windows

[Monolit](https://github.com/rawsense/monolit-client) — VPN-клиент, который пускает через VPN только то, что без него не открывается. Подписка monolit proxy подходит к нему как есть.
