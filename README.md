# monolit proxy

Панель для своего VPN на Xray. Ставится на VPS одной командой, потом всё делается в браузере. Добавляете человека, он получает ссылку, открывает её на телефоне и подключается. В списке видно, сколько трафика он потратил и до какого числа у него доступ.

## Что видит человек

По ссылке открывается страница подписки. На ней две кнопки: поставить приложение (INCY или Happ, есть для iPhone, Android и компьютера) и добавить в него подписку. Ключи руками копировать не надо. Если потом поменяете сервер, домен или протоколы, приложение подтянет это при следующем обновлении подписки.

## Возможности

- у каждого пользователя своя ссылка, лимит трафика и срок, есть трафик по дням и QR-код
- протоколы VLESS Vision, XHTTP, Hysteria2 и AmneziaWG (для AmneziaVPN), ненужные выключаются в окне «Протоколы»
- второй сервер (нода) подключается командой, которую даёт админка. Нода работает отдельным сервером или мостом: например, сервер в России принимает подключения и отправляет их на зарубежный. Российские сайты мост может открывать сам, со своего адреса
- наборы подключений: кому какие серверы показывать в приложении
- маршруты: какие сайты пускать напрямую, через Cloudflare WARP или блокировать
- прокси для Telegram (MTProto) и SOCKS5 с паролем, если нужны
- бэкап одним файлом: пользователи, ссылки, настройки. Восстановить можно перетаскиванием файла в админку
- если в nginx на сервере уже есть сайты, они продолжат работать
- домен можно сменить, старый останется запасным, и старые ссылки не сломаются
- обновление кнопкой в админке, версии берутся из релизов этого репозитория

Клиентские конфиги собираются по шаблону [autoXRAY](https://github.com/xVRVx/autoXRAY). Когда там выходит новая версия, monolit сам её забирает и проверяет через `xray run -test`. Не прошла проверку, значит, остаётся старая.

## Установка

Нужен сервер на Debian или Ubuntu, root и домен, который указывает на этот сервер.

```bash
git clone https://github.com/rawsense/monolit-proxy.git
cd monolit-proxy
bash install.sh
```

Установщик спросит домен и покажет, что собирается сделать. После подтверждения он ставит Xray, получает сертификат и настраивает nginx, а в конце пишет адрес админки, логин и пароль.

Чтобы обойтись без вопросов: `bash install.sh --domain vpn.example.ru`. Остальные ключи описаны в начале `install.sh`.

Если Xray уже настроен через autoXRAY, monolit возьмёт его входы как есть. Можно и заменить настройку autoXRAY своей: `bash install.sh --reconfigure --replace-autoxray`, но старые ключи autoXRAY тогда перестанут работать.

Обновить можно кнопкой в «Обслуживании» или повторным запуском `install.sh`. Пользователи, адрес админки и пароль не сбрасываются.

Удалить: `bash install.sh --uninstall`. Nginx и Xray вернутся к тому, что было до установки, база пользователей останется в `/var/lib/monolit`.

Перед каждой правкой конфигов Xray и nginx установщик сохраняет копии в `/root/backups`. Если после правки проверка не прошла или сайты на сервере перестали открываться, он откатывает всё обратно.

## Разработка

- `server/` сервер на Node 24 без зависимостей, база на `node:sqlite`
- `ui/src/` страницы админки и подписки, собираются в `ui/dist` командой `node ui/build.mjs`. `admin.html` и `sub.html` можно открыть без сервера, там будут демо-данные
- `awg/` сервер AmneziaWG в отдельном контейнере, собирается на сервере из исходников amneziawg-go
- тесты: `node --test --test-timeout=30000 --test-force-exit test/awg.test.mjs`

## Клиент для Windows

У нас есть свой клиент, [Monolit](https://github.com/rawsense/monolit-client). Он пускает через VPN только то, что без него не открывается, и подписку monolit proxy принимает как есть.
