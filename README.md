# monolit proxy

Панель для своего VPN на Xray. Ставится на VPS одной командой, а дальше всё делается в браузере. Вы добавляете человека, он получает ссылку, открывает её на телефоне и подключается. В списке пользователей видно, сколько трафика каждый потратил и до какого числа у него доступ.

## Что видит человек

По ссылке открывается страница подписки с двумя кнопками: первая ставит приложение (INCY или Happ, они есть для iPhone, Android и компьютера), вторая добавляет в него подписку. Копировать ключи руками не нужно. Если вы потом поменяете сервер, домен или протоколы, приложение подтянет изменения при следующем обновлении подписки.

## Возможности

- у каждого пользователя своя ссылка, лимит трафика и срок. Там же — трафик по дням и QR-код для телефона
- протоколы VLESS Vision, XHTTP, Hysteria2 и AmneziaWG (для AmneziaVPN). Ненужные выключаются в окне «Протоколы»
- второй сервер (нода) подключается командой, которую даёт админка. Нода работает отдельным сервером или мостом: например, сервер в России принимает подключения и передаёт их зарубежному. Российские сайты мост может открывать сам, со своего адреса
- наборы подключений: кому какие серверы показывать в приложении
- маршруты: какие сайты пускать напрямую, какие через Cloudflare WARP, а какие блокировать
- прокси для Telegram (MTProto) и SOCKS5 с паролем, если нужны
- бэкап одним файлом: пользователи, ссылки, настройки. Чтобы восстановить, файл достаточно перетащить в админку
- уживается с сайтами, которые уже есть в nginx на сервере
- домен можно сменить: прежний останется запасным, и выданные ссылки продолжат работать
- обновление кнопкой в админке, новые версии берутся из релизов этого репозитория

Клиентские конфиги собираются по шаблону [autoXRAY](https://github.com/xVRVx/autoXRAY). Когда выходит новая версия шаблона, monolit забирает её сам и проверяет через `xray run -test`. Если проверка не прошла, остаётся прежняя.

## Установка

Нужен сервер на Debian или Ubuntu с доступом root и домен, который указывает на этот сервер.

```bash
git clone https://github.com/rawsense/monolit-proxy.git
cd monolit-proxy
bash install.sh
```

Установщик спросит домен и покажет, что собирается сделать. После подтверждения он ставит Xray, получает сертификат и настраивает nginx, а в конце пишет адрес админки, логин и пароль.

Чтобы установить без вопросов: `bash install.sh --domain vpn.example.ru`. Остальные ключи описаны в начале `install.sh`.

Если Xray уже настроен через autoXRAY, monolit возьмёт его входы как есть. Настройку autoXRAY можно и заменить своей: `bash install.sh --reconfigure --replace-autoxray`. Старые ключи autoXRAY после этого перестанут работать.

Обновить можно кнопкой в «Обслуживании» или повторным запуском `install.sh`. Пользователи, адрес админки и пароль сохранятся.

Удалить: `bash install.sh --uninstall`. Nginx и Xray вернутся к тому, что было до установки, а база пользователей останется в `/var/lib/monolit`.

Перед каждой правкой конфигов Xray и nginx установщик сохраняет копии в `/root/backups`. Если после правки проверка не прошла или сайты на сервере перестали открываться, он сам всё откатывает.

## Разработка

- `server/` — сервер на Node 24 без зависимостей, база на `node:sqlite`
- `ui/src/` — страницы админки и подписки. Собираются в `ui/dist` командой `node ui/build.mjs`. `admin.html` и `sub.html` открываются и без сервера, на демо-данных
- `awg/` — сервер AmneziaWG в отдельном контейнере, собирается на сервере из исходников amneziawg-go
- тесты: `node --test --test-timeout=30000 --test-force-exit test/awg.test.mjs`

## Клиент для Windows

У нас есть свой клиент — [Monolit](https://github.com/rawsense/monolit-client). Он пускает через VPN только то, что без него не открывается, а подписку monolit proxy принимает без настройки.
