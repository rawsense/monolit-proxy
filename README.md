# monolit proxy

monolit proxy — панель управления VPN-сервером на Xray, которая ставится на VPS одной командой и позволяет раздавать доступ людям: у каждого пользователя своя ссылка на подписку, лимит трафика и срок действия.

## Подписка

По ссылке открывается страница, на которой человек выбирает приложение, INCY или Happ, устанавливает его и одной кнопкой добавляет в него подписку. Если на сервере что-то меняется, например домен, протоколы или список серверов, приложение подтягивает изменения при следующем обновлении подписки, а ссылка остаётся прежней.

## Возможности

Панель выдаёт подключения по VLESS Vision, XHTTP и Hysteria2, а также по AmneziaWG, для которого в подписку добавляется ссылка `vpn://` для AmneziaVPN. Ненужные протоколы можно отключить в окне «Протоколы».

К основному серверу можно подключить дополнительные (ноды): админка выдаёт команду, которую достаточно запустить на новом сервере. Нода может работать как самостоятельный сервер или как мост, когда сервер в России принимает подключения и передаёт их на зарубежный, при этом российские сайты мост может открывать сам, со своего адреса. С помощью наборов подключений можно настроить, какие серверы увидит в приложении каждый пользователь.

В маршрутах задаётся, какие сайты пускать напрямую, какие через Cloudflare WARP, а какие блокировать. При желании на сервер можно поставить MTProto-прокси для Telegram и SOCKS5 с паролем.

В карточке пользователя видны трафик по дням и QR-код для телефона. Всех пользователей, ссылки и настройки можно сохранить в один файл и потом восстановить из него. Если на сервере в nginx уже есть сайты, панель встаёт рядом с ними и их не ломает. Домен можно сменить, сохранив старый как запасной, чтобы выданные ранее ссылки продолжали работать. Обновляется панель кнопкой из админки, новые версии берутся из релизов этого репозитория.

Шаблон клиентских конфигов берётся из [autoXRAY](https://github.com/xVRVx/autoXRAY). Новые версии шаблона monolit подтягивает сам и применяет только после проверки через `xray run -test`.

## Установка

Для установки нужен сервер на Debian или Ubuntu с доступом root и домен, направленный на этот сервер.

```bash
git clone https://github.com/rawsense/monolit-proxy.git
cd monolit-proxy
bash install.sh
```

Установщик спросит домен, покажет, что собирается сделать, и после подтверждения поставит Xray, выпустит сертификат и настроит nginx, а в конце выведет адрес админки, логин и пароль. Чтобы установить без вопросов, домен можно передать сразу: `bash install.sh --domain vpn.example.ru`. Остальные ключи описаны в начале `install.sh`.

Если на сервере уже настроен autoXRAY, monolit подхватит его входы. Чтобы заменить настройку autoXRAY своей, запустите `bash install.sh --reconfigure --replace-autoxray`, но имейте в виду, что старые ключи autoXRAY после этого перестанут работать.

Обновить панель можно кнопкой в разделе «Обслуживание» или повторным запуском `install.sh`, пользователи и пароль при этом сохраняются. Удаляется она командой `bash install.sh --uninstall`, после которой nginx и Xray возвращаются к состоянию до установки, а база пользователей остаётся в `/var/lib/monolit`.

Перед каждой правкой конфигов Xray и nginx установщик сохраняет их копии в `/root/backups` и откатывает изменения, если проверка не прошла или сайты на сервере перестали открываться.

## Разработка

Сервер в `server/` написан на Node 24 без зависимостей и хранит данные в `node:sqlite`. Страницы админки и подписки лежат в `ui/src/` и собираются в `ui/dist` командой `node ui/build.mjs`, при этом `admin.html` и `sub.html` можно открыть и без сервера, они покажут демо-данные. В `awg/` находится сервер AmneziaWG, который работает в отдельном контейнере и собирается на сервере из исходников amneziawg-go.

Тесты запускаются так:

```bash
node --test --test-timeout=30000 --test-force-exit test/awg.test.mjs
```

## Клиент

Для Windows есть клиент [Monolit](https://github.com/rawsense/monolit-client), который пускает через VPN только заблокированные сайты и принимает подписку monolit proxy без дополнительной настройки.
