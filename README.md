# monolit proxy

Панель для своего VPN на Xray. Ставится на VPS одной командой, людей вы добавляете в браузере: каждому своя ссылка, лимит трафика и срок. В списке видно, кто сколько потратил и у кого доступ скоро закончится.

## Что видит человек

Ссылка открывает страницу подписки. Сверху выбор приложения, INCY или Happ, ниже две кнопки: поставить приложение из App Store, Google Play или с сайта и добавить в него подписку. Когда вы меняете сервер, домен или протоколы, приложение подхватывает это при следующем обновлении подписки, ссылку переотправлять не надо.

## Что ещё умеет

- VLESS Vision, XHTTP, Hysteria2 и AmneziaWG (для AmneziaVPN, ссылкой `vpn://`). Ненужные протоколы выключаются в окне «Протоколы»
- вторые серверы (ноды). В админке берёте команду, запускаете её на новом сервере и ждёте, пока в списке нод он станет «На связи». Нода может работать сама по себе или мостом: сервер в России принимает подключения и передаёт их на зарубежный, а российские сайты открывает сам, со своего адреса
- наборы: кому какие серверы показывать в приложении. Удобно, если мост нужен не всем
- маршруты: что пускать напрямую, что через Cloudflare WARP, а что блокировать. Правила проверяются сверху вниз
- по желанию прокси для Telegram (MTProto, FakeTLS) и SOCKS5 с паролем
- бэкап одним файлом с пользователями, ссылками, маршрутами и ключами WARP. Для восстановления файл перетаскивается в «Обслуживание»
- если на сервере в nginx уже есть сайты, они продолжат работать
- домен можно сменить: прежний останется запасным, и старые ссылки не сломаются
- обновление кнопкой, версии берутся из релизов этого репозитория

Клиентские конфиги собираются по шаблону [autoXRAY](https://github.com/xVRVx/autoXRAY). Когда автор выпускает новый шаблон, monolit скачивает его и прогоняет через `xray run -test`. Не прошёл — остаётся прежний.

## Установка

Нужны сервер на Debian или Ubuntu с root и домен, направленный на этот сервер.

```bash
git clone https://github.com/rawsense/monolit-proxy.git
cd monolit-proxy
bash install.sh
```

Установщик спросит домен, расскажет, что собирается делать, и после вашего «да» поставит Xray, получит сертификат Let's Encrypt и настроит nginx. В конце он выведет адрес админки, логин и пароль.

Без вопросов: `bash install.sh --domain vpn.example.ru`. Остальные ключи с описанием — в начале `install.sh`.

Если Xray у вас уже настроен через autoXRAY, monolit возьмёт его входы как есть. Можно и заменить настройку autoXRAY своей (`bash install.sh --reconfigure --replace-autoxray`), только старые ключи autoXRAY после этого работать перестанут.

Обновляется кнопкой в «Обслуживании» или повторным запуском `install.sh`, пользователи и пароль при этом остаются. Удаляется командой `bash install.sh --uninstall`: nginx и Xray вернутся к тому, что было до установки, а база пользователей останется в `/var/lib/monolit`.

Прежде чем трогать конфиги Xray и nginx, установщик кладёт их копии в `/root/backups`. Если после правки проверка не прошла или сайты на сервере перестали открываться, он возвращает всё как было.

## Разработка

- `server/` — сервер на Node 24 без зависимостей, база на `node:sqlite`
- `ui/src/` — страницы админки и подписки, `node ui/build.mjs` собирает их в `ui/dist`. `admin.html` и `sub.html` можно открыть и без сервера, там демо-данные
- `awg/` — сервер AmneziaWG в отдельном контейнере, собирается на сервере из исходников amneziawg-go
- тесты: `node --test --test-timeout=30000 --test-force-exit test/awg.test.mjs`

## Клиент для Windows

Для компьютера у нас есть свой клиент, [Monolit](https://github.com/rawsense/monolit-client). Он пускает через VPN только заблокированное, а подписку monolit proxy понимает сразу.
